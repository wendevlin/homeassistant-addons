# Homedocs (Beta)

Document your home with Markdown, right inside Home Assistant.

- Read and edit your docs in the browser, or edit the markdown files directly
- Choose which users can edit
- Print or save pages as PDF
- Share a page or a folder with a QR code, e.g. stuck on a device, without a Home Assistant login

I document things I don't need very often, like the yearly maintenance of the heating, and keep all
manuals in one place. QR codes on the devices lead straight to their page.

The code lives in [wendevlin/homedocs](https://github.com/wendevlin/homedocs).
